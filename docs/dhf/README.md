# Design history file (DHF)

NeuroMR-PRO is developed as medical-device software: IEC 62304 safety class B, risk management to ISO 14971, usability to IEC 62366-1, security to IEC 81001-5-1. This folder holds the evidence and is maintained during development, not afterwards.

| Document | File | Status (Phase 0) |
|---|---|---|
| Software development plan | `SDP.md` | Baseline |
| Software requirements | `../spec/FUNCTIONAL_SPEC.md` (IDs `AREA-NNN`) | Baseline v0.1 |
| Algorithm design | `../spec/ALGORITHMS.md` | Baseline v0.1 |
| Traceability matrix | `TRACEABILITY.md` (generated by `scripts/trace.py`) | Generated in CI |
| SOUP list | `SOUP.md` | Phase 0 dependencies |
| Risk management file | `RISK.md` | Initial hazard analysis |
| Architecture document | `ARCHITECTURE.md` | Phase 2 |
| Usability engineering file | `USABILITY.md` | Phase 1 (use specification) and Phase 11 (summative) |
| Cybersecurity file, threat model | `SECURITY.md` | Phase 2 |
| Verification report | `VERIFICATION.md` | Each release |
| Anomaly list and release notes | `ANOMALIES.md`, `RELEASE_NOTES.md` | Each release |
